# 평가 시연 대본

평가자 앞에서 아래 순서대로 진행하면 핵심 기능과 Git 학습 결과를 짧게 보여줄 수
있습니다. `입력` 열의 값만 차례로 입력하고, 설명 문장은 그대로 읽어도 됩니다.

| 단계 | 입력 또는 명령 | 확인할 내용 | 평가자에게 설명할 한 문장 |
|---:|---|---|---|
| 1 | `python -m unittest -v` | 50개 테스트, `OK` | “기본 데이터부터 데모 복원까지 50개 자동 테스트가 모두 통과합니다.” |
| 2 | `python main.py` | 제목, 메뉴 1~8과 0 | “Python 콘솔에서 입력을 받아 기능별 함수로 처리합니다.” |
| 3 | `2` | 기본 프롬프트 7개 | “프롬프트는 딕셔너리 7개를 담은 리스트로 관리합니다.” |
| 4 | `3` 후 `1` | 텍스트 생성 결과 | “카테고리 이름만 둔 것이 아니라 실제 데이터를 필터링합니다.” |
| 5 | `3` 후 `2` | 이미지 생성 결과 | “이미지 생성에도 실제 프롬프트가 있습니다.” |
| 6 | `3` 후 `3` | 영상 생성 결과 | “영상 생성 데이터도 같은 필터 로직으로 조회합니다.” |
| 7 | `3` 후 `4` | 페르소나 결과 | “페르소나 카테고리도 실제 데이터로 확인됩니다.” |
| 8 | `3` 후 `5` | 자동화 결과 2개 | “기존 미션 데이터 두 개를 보존했습니다.” |
| 9 | `3` 후 `6` | 기타 결과 | “여섯 기본 카테고리가 모두 비어 있지 않습니다.” |
| 10 | `7` | 아침 이슈 브리핑 | “최초 실행부터 즐겨찾기 목록의 실제 결과를 볼 수 있습니다.” |
| 11 | `4` 후 `썸네일` | 검색 성공 | “제목과 내용에서 부분 문자열을 검색합니다.” |
| 12 | `4` 후 `없는검색어` | 결과 없음 안내 | “결과가 없어도 프로그램이 중단되지 않습니다.” |
| 13 | `6` 후 `2` | 즐겨찾기 추가 | “딕셔너리의 Boolean 값을 실제로 반대로 바꿉니다.” |
| 14 | `7` | 변경 즉시 반영 | “같은 실행 중이므로 바뀐 상태가 바로 보입니다.” |
| 15 | `8` | 데모 1/6~6/6 | “추가 입력 없이 실제 데이터와 기존 함수로 전체 기능을 시연합니다.” |
| 16 | `1` | 아래 신규 데이터 입력 | “빈 입력 검증과 새 카테고리 추가를 함께 확인합니다.” |
| 17 | `2` | 신규 데이터 유지 | “프로그램이 실행되는 동안 추가 데이터가 유지됩니다.” |
| 18 | `0` | 정상 종료 | “종료 번호는 0이며 traceback 없이 끝납니다.” |
| 19 | `python main.py` 후 `2` | 다시 기본 7개 | “프로세스를 다시 시작하면 과제 요구대로 기본값으로 초기화됩니다.” |
| 20 | `7` | 기본 즐겨찾기 복원 | “즐겨찾기도 아침 이슈 브리핑 하나로 복원됩니다.” |
| 21 | `0` | 정상 종료 | “두 번째 실행도 정상 종료합니다.” |
| 22 | `git log --oneline --graph --all` | 브랜치·병합 기록 | “기존 커밋과 feature 브랜치 병합 이력을 보존했습니다.” |

## 신규 프롬프트 입력 예시

메뉴 `1`을 선택한 뒤 다음처럼 입력합니다.

```text
제목: (Enter)
제목: Python 반복문 연습
내용: (Enter)
내용: for와 while의 차이를 예제로 설명해 줘.
번호 선택 또는 새 카테고리 직접 입력: 코딩 실습
```

빈 제목과 내용에서 재입력 안내가 나오고, 마지막에는
`프롬프트가 추가되었습니다!`가 출력되어야 합니다.

## 잘못된 입력 빠른 확인

메인 메뉴에서 `abc`, `-1`, `99`를 차례로 입력합니다. 매번
`올바른 메뉴 번호를 입력해 주세요.`가 출력되고 메인 메뉴로 돌아오면 정상입니다.

상세 보기에서는 `문자`, `0`, `-1`, `99`를 입력한 뒤 정상 번호 `1`을 입력합니다.
오류 안내 후 상세 내용이 표시되고 traceback이 없어야 합니다.
