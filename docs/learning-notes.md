# 초보자 학습 노트

## 지금 아주 간단히 말하면

지금 하는 일은 **자주 쓰는 AI 지시문을 정리하는 작은 디지털 서랍장**을 만드는
것입니다. 프롬프트 하나가 서류 한 장이라면, 카테고리는 서랍 이름이고,
즐겨찾기는 자주 보는 서류에 붙이는 표시입니다. Git은 작업 과정을 시간순으로
남기는 복구 기록이고, GitHub는 그 기록을 인터넷 저장소에 보관하는 곳입니다.

## Python과 코딩 기초 용어

| 용어 | 정확한 뜻과 쉬운 비유 | 이 프로젝트에서의 적용 |
|---|---|---|
| Python | 사람이 읽기 쉬운 문법을 가진 프로그래밍 언어. 컴퓨터에게 일을 적어 주는 언어입니다. | `main.py`와 `test_main.py`를 작성하고 실행합니다. |
| 프로그램 | 입력을 받아 정해진 규칙으로 처리하고 결과를 내는 명령의 모음입니다. | 메뉴 입력 → 데이터 처리 → 콘솔 출력의 전체 흐름입니다. |
| 코드 | 프로그램을 만들기 위해 사람이 작성한 명령문입니다. | `main.py` 안의 변수, 조건문, 함수가 모두 코드입니다. |
| 변수 | 값을 담고 이름을 붙인 상자입니다. | `choice`, `title`, `content`, `results`에 값을 담습니다. |
| 문자열(`str`) | 글자를 저장하는 자료형입니다. | 프롬프트 제목·내용·카테고리와 사용자 입력입니다. |
| 불리언(`bool`) | 참 또는 거짓 두 값만 가진 자료형입니다. | `favorite`의 `True`와 `False`입니다. |
| 리스트(`list`) | 순서대로 여러 값을 담는 서랍입니다. | `categories`와 `prompts`가 여러 항목을 순서대로 저장합니다. |
| 딕셔너리(`dict`) | 이름표가 붙은 여러 값을 한 묶음으로 보관합니다. | 프롬프트 하나에 `title`, `content`, `category`, `favorite`를 저장합니다. |
| 조건문 | 조건에 따라 다른 일을 하게 하는 갈림길입니다. | `if`/`elif`/`else`로 메뉴와 입력값을 구분합니다. |
| 반복문 | 같은 일을 조건에 맞게 되풀이합니다. | `while`은 메뉴·재입력, `for`는 목록 출력을 담당합니다. |
| 함수 | 자주 쓰는 작업을 이름 붙여 묶은 작은 도구입니다. | `add_prompt()`, `show_list()`, `search_prompt()` 등으로 기능을 나눕니다. |
| `append()` | 리스트의 맨 뒤에 새 값을 추가합니다. | 신규 프롬프트와 신규 카테고리를 추가합니다. |
| `input()` | 콘솔에서 사용자가 입력한 글자를 받습니다. | 메뉴 번호와 프롬프트 정보를 입력받습니다. |
| `print()` | 값을 콘솔 화면에 보여줍니다. | 메뉴, 목록, 오류 안내, 결과를 출력합니다. |
| 콘솔 프로그램 | 버튼 대신 터미널의 글자 입력과 출력으로 사용하는 프로그램입니다. | PowerShell에서 `python main.py`로 실행합니다. |
| 모듈 | 다른 Python 코드에서 불러 쓸 수 있는 `.py` 파일입니다. | `test_main.py`가 `import main`으로 기능을 불러옵니다. |
| import | 다른 파일의 변수와 함수를 가져오는 동작입니다. | 테스트가 `main.py`를 불러오되 메뉴를 자동 실행하지 않습니다. |
| 테스트 | 예상한 입력에 예상한 결과가 나오는지 자동 확인하는 코드입니다. | `unittest` 50개가 기능과 예외 상황을 검증합니다. |
| traceback | 오류가 발생한 위치와 호출 순서를 보여주는 기록입니다. | 잘못된 입력에서도 traceback이 나오지 않도록 검증합니다. |

## 프로그램 구조와 데이터 흐름

```text
사용자 입력(input)
→ main()의 메뉴 조건문
→ 기능 함수 호출
→ prompts/categories 리스트 조회 또는 변경
→ 결과 출력(print)
→ 다시 메인 메뉴
```

데이터는 현재 실행 중인 Python 프로세스의 메모리에만 있습니다. 그래서 실행 중에는
추가·즐겨찾기 변경이 유지되지만, 종료하고 새 프로세스로 다시 실행하면 `main.py`
상단의 기본 데이터로 시작합니다. 이를 **종료 후 초기화**라고 합니다.

## Git과 GitHub 기초 용어

| 용어·명령 | 정확한 뜻과 쉬운 비유 | 이 프로젝트에서의 적용 |
|---|---|---|
| Git | 파일 변경 이력을 내 컴퓨터에 기록하는 버전 관리 도구입니다. 게임의 저장 지점과 비슷합니다. | 기능별 커밋과 병합 이력을 보존합니다. |
| GitHub | Git 저장소를 인터넷에서 보관·공유하는 서비스입니다. | 원격 `origin`에 프로젝트를 백업하고 제출합니다. |
| repository | 프로젝트 파일과 Git 이력을 함께 담는 저장소입니다. | `prompt-manager-aug` 폴더 전체입니다. |
| `git init` | 현재 폴더에서 새 Git 저장소를 시작합니다. | 원본 프로젝트를 처음 만들 때 사용한 명령입니다. |
| `git add` | 다음 커밋에 넣을 변경을 준비 영역에 올립니다. | 수정한 파일을 목적별로 선택합니다. |
| `git commit` | 준비한 변경을 설명과 함께 하나의 저장 지점으로 기록합니다. | `feat:`, `test:`, `docs:` 등의 기록을 남깁니다. |
| branch | 기존 이력에서 갈라져 안전하게 작업하는 평행 작업선입니다. | `feature/prompt-list`, `codex/prompt-manager-improvement`를 사용합니다. |
| `git checkout` | 다른 브랜치나 과거 상태로 이동하는 전통 명령입니다. | 기능 브랜치와 `main` 사이를 이동합니다. |
| `git switch` | 브랜치 이동에 집중한 새 명령입니다. | `git switch main`처럼 사용할 수 있습니다. |
| `git merge` | 한 브랜치의 변경을 다른 브랜치에 합칩니다. | 기능 브랜치를 테스트 후 `main`에 병합합니다. |
| `git clone` | 원격 저장소와 이력을 새 폴더에 통째로 복제합니다. | GitHub 최종본을 새 폴더에서 검증합니다. |
| `git pull` | 원격 변경을 받아 현재 브랜치에 합칩니다. | 다른 PC의 원격 변경을 로컬에 반영할 때 씁니다. |
| `git push` | 로컬 커밋을 원격 저장소에 보냅니다. | 검증된 `main`을 GitHub에 반영합니다. |

## 앞으로 자주 접할 개발 용어

| 용어 | 짧은 뜻 |
|---|---|
| 터미널 | 명령어를 글자로 입력하는 창입니다. |
| PowerShell | Windows에서 사용하는 터미널 셸과 명령 환경입니다. |
| CLI | 버튼 대신 명령어로 사용하는 프로그램 방식입니다. |
| 경로(path) | 컴퓨터에서 파일이나 폴더의 주소입니다. |
| PWD | 현재 터미널이 위치한 작업 폴더입니다. |
| working tree | 현재 눈앞의 실제 프로젝트 파일 상태입니다. |
| staging area | `git add`로 다음 커밋을 준비해 둔 영역입니다. |
| HEAD | 현재 체크아웃한 최신 커밋을 가리키는 표지입니다. |
| SHA | Git 커밋을 구별하는 고유 식별값입니다. |
| `main` | 보통 배포·제출할 안정적인 기본 브랜치입니다. |
| `origin` | clone할 때 등록되는 기본 원격 저장소 별명입니다. |
| `git status` | 현재 브랜치와 변경 파일 상태를 확인합니다. |
| `git log` | 커밋 이력을 시간순으로 확인합니다. |
| `git fetch` | 원격 최신 정보만 받아오고 내 파일에는 아직 합치지 않습니다. |
| conflict | 서로 같은 부분을 다르게 바꿔 Git이 자동으로 합치지 못한 상태입니다. |
| 프로세스 | 실행 중인 프로그램 한 개의 작업 단위입니다. |
| 메모리 | 실행 중 데이터를 잠시 보관하는 공간입니다. |
| 영속화 | 종료 후에도 데이터를 파일이나 DB에 남기는 방식입니다. 이번 과제에는 사용하지 않습니다. |
| 표준 라이브러리 | Python 설치에 기본 포함된 도구 모음입니다. `unittest`가 예입니다. |
| 의존성 | 프로그램 실행에 필요한 다른 패키지나 환경입니다. 이번 필수 기능은 외부 의존성이 없습니다. |

## 학습 목표와 현업 연결

- 자료구조로 여러 데이터를 일관되게 표현합니다.
- 조건문과 반복문으로 입력 오류와 메뉴 흐름을 제어합니다.
- 함수로 기능을 나누어 수정과 테스트를 쉽게 만듭니다.
- 자동 테스트로 “될 것 같다”가 아니라 실제 결과를 확인합니다.
- Git 브랜치와 커밋으로 작업을 작은 단위로 추적하고 복구합니다.
- 현업에서는 같은 원리가 고객 목록, 재고, 업무 템플릿, 콘텐츠 관리 도구로 확장됩니다.
