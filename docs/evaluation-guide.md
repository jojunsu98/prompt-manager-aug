# 평가 가이드

이 문서는 **코디세이 AI 학습 프롬프트 관리함**의 공식 요구사항과 실제 구현을
빠르게 대조하기 위한 자료입니다. 이 프로그램은 프롬프트를 AI에 전송하는 실행기가
아니라, 메모리에 저장된 프롬프트를 관리하는 Python 콘솔 프로그램입니다.

## 1. 공식 요구사항 체크리스트

| 요구사항 | 실제 구현 위치 | 확인 방법 |
|---|---|---|
| Python 3.10 이상 | 프로젝트 실행 환경 | `python --version` |
| 메뉴 1~8, 종료 0 | `show_menu()`, `main()` | 실행 직후 메뉴 확인 |
| 잘못된 메뉴 입력 처리 | `main()`의 `else` | `abc`, `-1`, `99` 입력 |
| 기존 프롬프트 3개 보존 | `prompts` | 메뉴 2에서 제목 확인 |
| 기본 프롬프트 7개 | `prompts` | 메뉴 2의 총 개수 확인 |
| 리스트와 딕셔너리 | `categories`, `prompts` | `main.py` 상단 확인 |
| 네 필드 | 각 프롬프트 딕셔너리 | `title`, `content`, `category`, `favorite` 확인 |
| 빈 제목·내용 재입력 | `add_prompt()` | 메뉴 1에서 Enter만 입력 |
| 기본·직접 입력 카테고리 | `add_prompt()` | 번호 선택 및 `코딩 실습` 직접 입력 |
| 새 프롬프트의 즐겨찾기 기본값 `False` | `add_prompt()` | 추가 직후 목록의 `[일반]` 확인 |
| 전체 목록 | `show_list()` | 메뉴 2 |
| 빈 목록·빈 결과 안전 처리 | 각 조회 함수의 빈 결과 조건문 | 자동 테스트 18·20·31·38번 |

| 상세 보기와 번호 검증 | `show_detail()` | 메뉴 5에서 정상·잘못된 번호 입력 |
| 즐겨찾기 추가·해제 | `toggle_favorite()` | 메뉴 6에서 같은 번호 두 번 변경 |
| 즐겨찾기 목록 | `show_favorites()` | 메뉴 7에서 즉시 반영 확인 |
| 입력 없는 6단계 데모 | `run_evaluation_demo()` | 메뉴 8 한 번 입력 |
| 데모의 현재 데이터·실제 함수 사용 | `run_evaluation_demo()` | 자동 테스트 47번과 함수 호출 확인 |
| 데모 전체 데이터·즐겨찾기 복원 | `try`/`finally` | 자동 테스트 48·49번 |
| 실행 중 데이터 유지 | 전역 `prompts`, `categories` | 추가 후 메뉴 2·3에서 확인 |
| 종료 후 초기화 | 프로세스 메모리 방식 | 종료 후 재실행하여 확인 |

| 외부 라이브러리·LLM API 미사용 | `main.py` 전체 | import 목록과 네트워크 호출 부재 확인 |

## 2. 6개 기본 카테고리와 실제 데이터

| 번호 | 카테고리 | 기본 프롬프트 |
|---:|---|---|
| 1 | 텍스트 생성 | AI 기술 뉴스 3줄 요약 |
| 2 | 이미지 생성 | 제품 썸네일 이미지 생성 |
| 3 | 영상 생성 | 15초 제품 광고 영상 구성 |
| 4 | 페르소나 | 친절한 고객 상담가 페르소나 |
| 5 | 자동화 | 아침 이슈 브리핑, 개인 지출 자동 분류 |
| 6 | 기타 | 회의 준비 체크리스트 |

검증할 때는 메뉴 `3`을 한 번만 여는 것이 아니라, 메인 메뉴로 돌아올 때마다 다시
`3`을 선택한 뒤 카테고리 번호 `1`부터 `6`까지 각각 조회합니다.

## 3. 평가 추천 순서

1. `python -m unittest -v`로 50개 테스트의 `OK`를 확인합니다.
2. `python main.py`를 실행합니다.
3. 메뉴 `2`에서 기본 데이터 7개와 즐겨찾기 표시를 확인합니다.
4. 메뉴 `3`을 반복 선택하여 카테고리 1~6을 각각 조회합니다.
5. 메뉴 `7`에서 초기 즐겨찾기 `아침 이슈 브리핑`을 확인합니다.
6. 메뉴 `4`에서 검색 성공·실패·빈 검색어를 확인합니다.
7. 메뉴 `6`과 `7`로 즐겨찾기 변경이 즉시 반영되는지 확인합니다.
8. 메뉴 `8`로 입력 없는 6단계 자동 데모를 확인합니다.
9. 메뉴 `1`에서 새 프롬프트와 새 카테고리를 추가합니다.
10. 메뉴 `2`, `3`, `5`로 실행 중 데이터 유지를 확인합니다.
11. 문자·음수·`99` 메뉴가 안전하게 처리되는지 확인합니다.
12. 메뉴 `0`으로 종료하고 재실행하여 기본 상태 복원을 확인합니다.

## 4. 정상 출력 예시

```text
=== 코디세이 AI 학습 프롬프트 관리함 ===
1. [자동화] 아침 이슈 브리핑 [즐겨찾기]
2. [텍스트 생성] AI 기술 뉴스 3줄 요약 [일반]
총 7개의 프롬프트
```

```text
검색 결과가 없습니다.
프롬프트가 추가되었습니다!
평가용 기능 데모가 완료되었습니다.
프로그램을 종료합니다.
```

즐겨찾기는 emoji가 아니라 `[즐겨찾기]`, `[일반]`, `O`, `X`로 표시하여 Windows
CP949 콘솔에서도 출력 오류가 나지 않도록 했습니다.

## 5. 테스트와 Git 확인 명령

```powershell
python -m unittest -v
git branch --show-current
git status
git log --oneline --decorate --graph --all -30
```

정상 자동 테스트 결과는 다음 형태입니다.

```text
Ran 50 tests
OK
```

Git 로그에서는 기존 `feature/prompt-list` 커밋과
`merge: add prompt list feature` 병합 기록이 남아 있어야 합니다.

## 6. 종료 후 초기화 확인

첫 번째 실행에서 메뉴 `1`로 프롬프트를 추가하고 메뉴 `6`으로 즐겨찾기를
변경한 다음 `0`으로 종료합니다. 두 번째로 `python main.py`를 실행한 뒤 메뉴
`2`와 `7`을 확인합니다.

- 첫 실행에서 추가한 프롬프트는 사라져야 합니다.
- 기본 프롬프트는 다시 7개여야 합니다.
- 초기 즐겨찾기는 다시 `아침 이슈 브리핑`이어야 합니다.

이는 오류가 아니라, 과제 요구사항에 맞춰 데이터를 파일이나 DB에 저장하지 않고
현재 프로세스의 메모리에서만 관리한 결과입니다.
